The Money S3 Writer pushes data from Keboola Storage into the Money S3 ERP system (moneys3.eu) using its GraphQL mutation API. Each configuration row targets one Money S3 object (such as Company or IssuedInvoice) and maps source columns to the object's input fields. The writer supports both **create** and **update** write modes, optional per-record error handling (failed records are captured in the `write_log` output table instead of aborting the job), and a **document mode** for objects that carry line-item sub-collections (e.g. invoices) — in document mode a second input table supplies the line rows, joined to their header rows by a configurable key column. Field mapping is assisted by the **Re-load mapping** sync action, which introspects the selected endpoint's input type and fuzzy-matches incoming column names to API field names.
